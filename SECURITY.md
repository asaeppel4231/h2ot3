# Security Policy

## Supported Versions

Only the latest release candidate and the latest stable version are supported.

## Reporting a Vulnerability

If you discover a security vulnerability in h2ot3, please report it responsibly.

**Do not open a public GitHub issue.**  
Public issues may expose users to unnecessary risk before a fix is available.

Instead, please report the vulnerability privately by:

- Opening a *private* GitHub security advisory, or  
- Contacting the maintainer directly at: **asaeppel4231@gmx.de**

You can expect an initial response within **72 hours**.

If the vulnerability is confirmed, we will:

- Investigate and work on a fix as soon as possible  
- Coordinate a responsible disclosure  
- Credit you for the discovery (unless you prefer to remain anonymous)
