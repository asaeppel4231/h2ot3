# Roadmap

## Version 1.0.0

Here's a list of planned things for the version 1.0.0:

- new stack library as a subtree in src/core/thirdparty
- new queue library as a subtree in src/core/thirdparty
- new thread library as a subtree in src/core/thirdparty
- use threads instead of the callback module
- make the structures atomic (better for threads, e.g. lock free structures)
- refactor internal functions, CMake Files, API functions
- implement some backends
- implement the h2ot3 button
- new / add an event system
